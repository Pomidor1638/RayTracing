# 🌟 RayTracing Engine

Многопоточный рейтрейсер на C++ с поддержкой источников света, теней, отражений и интерактивным GUI.

![C++](https://img.shields.io/badge/C++20-Modern-green)
![SDL2](https://img.shields.io/badge/SDL2-Renderer-red)
![ImGui](https://img.shields.io/badge/ImGui-UI-purple)

---

## 📋 Особенности

| Фича | Описание |
| :--- | :--- |
| **🏗️ Архитектура сущностей** | Сферы, эллипсы, коробки с единым базовым классом |
| **💡 Источники света** | Светящиеся сферы с затуханием и тенями |
| **🪞 Зеркальные отражения** | Рекурсивная трассировка до 5 отскоков |
| **🌑 Backface Culling** | Отсечение задних граней (полые объекты) |
| **🎮 WASD + Мышь** | Полноценное управление камерой |
| **🖥️ ImGui GUI** | Редактирование сущностей в реальном времени |
| **🧵 Многопоточность** | Параллельный рендеринг на все ядра CPU |
| **⚡ Оптимизация** | Трансформация сущностей вместо лучей |

## 🚀 Быстрый старт

### Требования

| Компонент | Версия |
| :--- | :--- |
| **Компилятор** | GCC 10+ / MSVC 2019+ / Clang 12+ |
| **C++ Стандарт** | C++20 |
| **CMake** | 3.20+ |

### Зависимости

```bash
# Windows (vcpkg)
vcpkg install sdl2 glm imgui

# Linux (apt)
sudo apt install libsdl2-dev libglm-dev

# macOS (brew)
brew install sdl2 glm
```
